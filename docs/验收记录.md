**踩到的两个真 bug：**
1. `pythonw.exe` 下 `sys.stdout/stderr` 为 `None`，`log_message` 抛异常导致**连接被断开**——修法是 `_ensure_streams()` 把输出重定向到 `data/server.log`。

**实测**：冷启动（端口空闲）→ 引擎 4.2 秒就绪 → 页面资源（manifest/icon/state/kline）全部 200；
`pythonw` 单独启动 1.7 秒就绪。

## 六点十、双击即全屏（2026-10-18）

**问题**：`--start-fullscreen` 有时不生效——Edge/Chrome 已在运行时，新命令会复用已有进程，
启动参数被丢弃。

**修法**：启动器加独立配置目录，强制新进程：

```
--app=<url> --start-fullscreen --user-data-dir=%LOCALAPPDATA%\StockSystemApp
--no-first-run --no-default-browser-check
```

**实测（Win32 GetWindowRect）**：屏幕 1707×1067，应用窗口 1707×1067、位置 (0,0) → **判定全屏 ✓**。
另加守卫：窗口已满屏时不再调用 Fullscreen API，避免二次全屏闪烁。
