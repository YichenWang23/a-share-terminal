# 数据源可用性实测（2026-10-17 夜）

本文件是「行情主源为什么是腾讯而不是东财」的一手证据，供 spec 修订留档。

## 一、东方财富实测：间歇可用，主体不可用

客户端：Python 3.14.7 `urllib`，Header 带 `User-Agent` 与 `Referer: https://quote.eastmoney.com/`。

| 时间点 | 请求 | 结果 |
| --- | --- | --- |
| T1（本会话早期，多轮） | `push2` / `push2his`（多种 Header 组合） | 全部 `RemoteDisconnected` |
| T2（本轮，连续 3 次） | `push2` 报价 / `push2his` K 线 / `82.push2` | **3/3 成功**（151–327 B 正常 JSON） |
| T3（紧随其后，10 次、间隔 1s） | `push2` 报价 `secid=1.600519` | **0/10 成功**，10 次全是 `RemoteDisconnected`（57–127ms 即失败） |

结论：东财接口对来自本机的请求**大部分时间直接断连**，只有偶发窗口可用。
把它当主源，会让每次行情请求先白等一轮重试（默认 3 次、退避 0.6s/1.2s）再退化到腾讯，
用户能明显感觉到卡顿。

## 二、腾讯实测：稳定可用

| 类别 | 结果 |
| --- | --- |
| 报价（47 只一次批量） | 成功，23587 B |
| 日 K（47 只逐只） | **47/47 成功**（主票 320 根，其余 120 根） |
| 分时 | 成功（600519 共 267 点） |

## 三、结论与处理

- **主源 = 腾讯**（稳定），**备源 = 新浪**（报价），东财仅用于**代码搜索**（`searchapi` 一直稳定）。
- 这与最初 spec 里「东财为主、腾讯备用」不一致，属于**经实测后的方向性偏离**；
  处理方式是修订 spec 并保留本文件作为依据，而不是让文档与实现两张皮。
- 若将来东财恢复稳定，切主源需要：
  1. 改 `stock/datasource.py` 里 `get_quotes` / `get_kline` 的尝试顺序；
  2. **新增东财 quote/kline 解析器**——目前只有 `parse_em_search`，
     没有 `parse_em_quote` / `parse_em_kline`（本轮抓不到稳定成功样本，不凭猜测实现）；
  3. 前端不需要改。
