# A 股本地股票系统

一个**只在你本机跑**的 A 股看盘 / 模拟交易 / 回测工具。真实行情来自公开接口，
零第三方依赖（Python 标准库 + 浏览器原生 JS），双击 `启动.cmd` 就能用。

> 不接券商、不下真单、不碰真钱。所有交易都是本地模拟账本。
> 所有分析仅供参考，不构成投资建议。

## 快速开始

1. 双击 **`启动.cmd`**：后台启动引擎 → 浏览器以**应用模式全屏**打开（没有地址栏、没有标签页）
2. 浏览器地址：<http://127.0.0.1:8770/>
3. 关闭：在命令行窗口按 `Ctrl+C`

手动启动：

```bat
python server.py                 :: 自动开浏览器
python server.py --no-browser    :: 不开浏览器
python server.py --port 8771     :: 换端口
```

要求：Python 3.10+（开发与验收用的是 3.14.7）。**不需要 pip install 任何东西。**

## 数据来源与降级（实测结论）

| 用途 | 主源 | 备用 | 说明 |
| --- | --- | --- | --- |
| 实时行情 | 腾讯 `qt.gtimg.cn` | 新浪 `hq.sinajs.cn` | 腾讯直接给涨停/跌停价，GBK 编码 |
| 日 K 线 | 腾讯 `web.ifzq.gtimg.cn` | 本地缓存 | 前复权，最多 500 根 |
| 按名称查代码 | 东财 `searchapi.eastmoney.com` | 缓存 | 返回 `QuoteID` 可映射市场 |

**为什么不用东财的 quote/kline 做主源**（见 [`docs/数据源实测.md`](docs/数据源实测.md)：本机 10/10 次 `RemoteDisconnected`，只有偶发可用窗口）：在本机用 Python 直连会被 `RemoteDisconnected`
断开（换 4 种请求头组合都一样，见 `tools/probe_report.json`），而 web 抓取却能通——
这是它拒了 Python 的客户端指纹，不是参数问题。

降级链：**实时接口 → 磁盘缓存（标「缓存」）→ 录制样本（标「演示」）**。
拿不到实时数据时页面顶部会明确标注，绝不把样本数据伪装成实时行情。

## 常见问题

**Q：行情时间怎么是昨天的？**
非交易日或收盘后，行情就是最近一次收盘。页面会显示数据时间戳，不假装是实时。

**Q：回测一直是 0 笔交易？**
多半是资金买不起一手。界面会提示「100 股约需 X 元」。调大资金或换只便宜的票。

**Q：AI 建议为什么写着「规则引擎」？**
本程序不内置任何大模型。默认用可复现的本地规则（见 `stock/analysis.py` 注释里的打分口径）；
要真模型请在「设置」里填 OpenAI 兼容接口与 key，启用后来源会标注成模型名。

**Q：端口被占用？**
`python server.py --port 8771`，或用环境变量 `STOCK_PORT`。

**Q：能不能自动刷新/后台盯盘？**
不能，这是刻意的：只在页面操作时按需请求，不做后台定时抓取。

**Q：入金以后收益率怎么算？会不会把加钱当成赚了？**
不会。总收益 = 总资产 − **净入金**（入金 − 出金）。你加 5 万，净入金同步 +5 万，收益率不变；
只有真实盈亏才会让总收益变动。

**Q：权重占比怎么算？**
每只票的市值 ÷ 总资产（含现金），全场合计 100%。现金也算一项：满仓时股票合计接近 100%，
空仓时现金 100%。持仓表里也有一列「权重」。

**Q：页面提示「拿不到 XXX 的 K 线」怎么办？**
1) 服务端会自动重试 3 次（退避 0.6s/1.2s），前端再重试 2 次；
2) 仍不行就点详情页状态行右边的**「重试」**按钮；
3) 想弄清哪一环坏了：**设置 → 数据源诊断 → 运行诊断**，会实测「行情/日K/搜索/分时」四项并报耗时与错误；
4) 断网时自动用本地缓存，页面标「缓存」；连缓存都没有才用「演示」样本。

**Q：为什么一进来是自选股，不是个股图？**
故意的：先看列表更稳，个股数据在后台静默预载，点「看」就是现成的，避免首屏就撞上错误页。

**Q：双击 `启动.cmd` 后看不到控制台窗口，正常吗？**
不是，那个窗口**就是服务本体**，用的时候别关；停止按 `Ctrl+C` 或直接关窗口。

**Q：5 秒刷新到底更新什么？图表会跟着动吗？**
会，但不是所有东西都 5 秒一次：

| 元素 | 更新节奏 |
| --- | --- |
| 自选股表格、个股价格/涨跌幅 | **5 秒** |
| 日 K 的最后一根（开高低收/量），MA/RSI/MACD 一起重算 | **5 秒** |
| 分时图最后一点的价格 | **5 秒** |
| 分时图补上新的分钟（重拉整条分时） | **30 秒** |
| AI 建议（规则引擎/真模型） | **60 秒** |
| 持仓 / 账户页（停在该页时） | **5 秒** |

价格没变时不做重绘（不会闪）；非交易日价格不动，所以图也不会跳——这是正常的。

**Q：钱包是什么？入金/出金怎么走？**
钱包就是一张**假的银行卡**，开局 0（本金 35 万全在证券账户）。入金 = 从钱包转到证券账户（钱包不够就拒绝），
出金 = 从证券账户转回钱包。两边都记账、都能在「资金流水」里查；
钱包余额永远不为负。净资产 = 钱包 + 证券账户现金 + 持仓市值。

## 桌面应用模式（推荐）

双击桌面图标 → 引擎在后台静默启动（无控制台窗口）→ 浏览器以**应用模式全屏**打开：
没有地址栏、没有标签页、没有书签栏，按 `Ctrl+W` 或关窗口即退出。

| 项 | 说明 |
| --- | --- |
| `启动.cmd` | 应用模式启动器：后台起引擎 → Edge/Chrome 用 `--app` + `--start-fullscreen` 全屏打开 |
| `static/manifest.webmanifest` | PWA 清单（`display: fullscreen`），也支持在 Edge/Chrome 里「安装此站点为应用」 |
| 后台日志 | 无控制台时输出写到 `data/server.log` |

> 为什么不能"打开就全屏"：浏览器安全策略禁止网页自行全屏，必须由用户操作触发。
> 应用模式启动参数 `--start-fullscreen` 绕过了这条限制，所以双击图标就能直接全屏。

输出多尺寸 `icon.ico`（16/32/48/64/128/256）。
